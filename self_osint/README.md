# أداة فحص البصمة الرقمية الذاتية (Self-OSINT)

أداة سطر أوامر تفحص **ما هو مكشوف عنك أنت** في المصادر المفتوحة، وتُخرج تقريرًا
مرتّبًا حسب الخطورة مع خطوة عملية لكل نتيجة.

## نطاق الاستخدام

الأداة مصمَّمة لفحص **معرّفاتك أنت** — أو معرّفات تملك تفويضًا صريحًا مكتوبًا بفحصها
(مثل نطاق شركتك ضمن اختبار اختراق مُصرَّح به). استخدامها لملاحقة أفراد أو جمع
معلومات عن أشخاص بدون علمهم خارج الغرض الذي بُنيت له.

كل الطلبات التي ترسلها الأداة هي طلبات عامة عادية (GET على صفحات وواجهات علنية) —
لا تسجيل دخول، ولا تخمين كلمات مرور، ولا التفاف على أي حماية.

## المصادر المدعومة

| المصدر | ما يفحصه | يتطلب |
|---|---|---|
| `hibp` | تسريبات، لصقات عامة (pastes)، وسجلات برامج سرقة البيانات لإيميلك | مفتاح `HIBP_API_KEY` |
| `gravatar` | ملف Gravatar عام مرتبط بإيميلك (اسم، موقع، حسابات مرتبطة) | — |
| `usernames` | وجود اسم المستخدم على ~19 منصة عامة | — |
| `github` | البيانات المعلنة في ملفك العام + إيميلات مكشوفة في نشاطك | `GITHUB_TOKEN` (اختياري) |
| `git-history` | إيميلات شخصية وملفات أسرار في سجل مستودع محلي | — |

## التثبيت

```bash
pip install -r requirements.txt
cp .env.example .env   # ثم ضع مفاتيحك
```

## الاستخدام

```bash
# فحص كامل
python main.py scan --email you@example.com --username your_handle --repo /path/to/repo

# مصادر محددة فقط
python main.py scan --username your_handle --sources usernames,github

# تقرير Markdown في ملف
python main.py scan --email you@example.com --format markdown --output report.md

# مخرجات JSON للمعالجة الآلية
python main.py scan --username your_handle --format json

# في CI: رمز خروج 1 إذا وُجدت نتيجة بخطورة high أو أعلى
python main.py scan --email you@example.com --fail-on high
```

يمكن تكرار `--email` و`--username` و`--repo` لفحص أكثر من معرّف في نفس التقرير.

## مستويات الخطورة

`critical` > `high` > `medium` > `low` > `info` — تُرتَّب النتائج تنازليًا في التقرير.
مثال: كلمة مرور في تسريب = `critical`، ملف `.env` في سجل Git = `high`،
تكرار اسم المستخدم عبر منصات = `medium`.

## عن دقة فحص أسماء المستخدمين

كثير من المنصات تُعيد `HTTP 200` مع صفحة "الحساب غير موجود" (soft-404)، فاعتبار كل
رد 200 حسابًا موجودًا ينتج تقريرًا مليئًا بحسابات وهمية. لذلك تفحص الأداة كل منصة
**مرتين**: باسم المستخدم الهدف، وباسم عشوائي مؤكَّد عدم وجوده (control). لا يُعلَن
الحساب موجودًا إلا إذا أثبتت المنصة قدرتها على التمييز بين الاثنين.

النتيجة أن الأداة تفضّل قول **"تعذّر الحسم — افحص يدويًا"** على التخمين. المنصات التي
تحجب الفحص الآلي (403/429) تُدرَج تحت `info` مع روابطها للفحص اليدوي؛ هذا شائع عند
التشغيل من شبكات سحابية أو خلف بروكسي، ويقلّ كثيرًا عند التشغيل من جهازك.

## البنية

```
self_osint/
├── main.py                    # واجهة سطر الأوامر
├── findings.py                # Finding / ScanReport ومنطق الخطورة
├── report.py                  # عرض: طرفية / Markdown / JSON
├── sources/
│   ├── hibp.py                # Have I Been Pwned
│   ├── gravatar.py            # ملف Gravatar من بصمة الإيميل
│   ├── usernames.py           # فحص المنصات مع معايرة ضد الإيجابيات الكاذبة
│   ├── github_profile.py      # ملف GitHub العام والنشاط
│   └── git_history.py         # سجل مستودع محلي
├── tests/
│   ├── test_findings.py
│   └── test_sources.py
├── requirements.txt
└── .env.example
```

## الاختبارات

```bash
python -m pytest tests/ -q
```

الاختبارات لا تُجري أي طلب شبكة: منطق التصنيف والمعايرة يُختبر باستجابات محضَّرة،
وفحص Git يُختبر على مستودعات مؤقتة تُنشأ أثناء الاختبار.
